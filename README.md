# SQL-Injection
My Solutions to the PortSwigger Web Security Academy of Course SQL Injection, With Python payloads and step by step Explanation to each lab

## About

Each lab in this repo has its own folder containing:
- A Python script that automates the exploit
- A plain-text explanation file breaking down the vulnerability, the attack, and how the script works
